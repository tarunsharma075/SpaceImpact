2026-11-22 — Game joystick movement (approved)
- Used the existing JoyStick UI Image and its child Button in Assets/Scenes/Game.unity. Added GameplayControlsUI to the JoyStick parent and assigned the child Button as its thumb; no new control graphics are generated by code.
- GameplayControlsUI.cs converts pointer position into the joystick's local coordinates, clamps the thumb's travel so it stays inside the outer circle, snaps it to the nearest cardinal axis, and returns it to center on release. Diagonal thumb/player input is disabled. A dead zone prevents input when the thumb is near center. Only one pointer controls the joystick at a time.
- The user reported that the thumb looked smaller in Play Mode than in Scene view. Removed the Awake-time thumb size/anchor override so the child retains its authored RectTransform size, anchors, and pivot. The travel radius is based on the visible sprite area to keep the existing-size thumb inside the outer circle.
- PlayerController.cs reads this joystick input, moves the Rocket, clamps its full RectTransform to Screen.safeArea and the play area, and uses ScorePanel's lower edge as the upper movement limit.
- PlayerController.cs exposes independent serialized Up, Down, Forward, and Backward speed values. Forward maps to right because the ship faces right; it defaults to 2.25 while the other directions default to 5. The existing fire button and its behavior were left unchanged.
- Removed the stale PlayerView component reference from the Game Rocket object because the View script had been removed earlier.
- No Unity Play Mode/runtime verification has been performed yet.
